The context behind the numbers.

What was measured?

168 catalog searches: the same 14 movie and 14 show queries for each provider. AIOMetadata’s Stremio search route, normal metadata enrichment, and complete responses were measured. This is an independent community test; it does not measure Odin rendering or Jellyfin search routing.

How are accuracy and missing IDs handled?

Each media type has 11 reviewed title queries. Alias, franchise, and negative cases are shown for exploration but excluded from title accuracy. Matching uses expected IMDb IDs. TVDB has two show cases with unmapped IDs in the top five; confirmed-hit scores are lower bounds where marked with an asterisk. A result at rank 9 is a miss at top 5, but a hit at top 10. This measures target discovery, not the relevance of every returned title.

Were searches cold? What changed during the run?

Providers had isolated caches and equal four-query pilots. Every main query executed a provider lookup; metadata caches evolved naturally. These were not fully cold searches. All six test apps restarted after 25 queries per provider with disk/Redis retained; the last three queries per provider form a separate restart cohort. Scheduled background jobs were disabled in test copies. Production settings and caches were unchanged.

Can I remove trailers or enrichment from the timings?

No trailer entries or addon-trailer calls were observed. Stage spans overlap and instrumentation does not cover every enrichment step. You cannot subtract stage times to estimate a feature-disabled response. The timing selector changes which observed searches are included; it does not simulate disabling features.

How reliable are these results?

This is one block of a proposed 1,680-search corpus, with a single timing per query. It is exploratory, not a universal ranking. Four Lumiere responses matched the original search code byte-for-byte after canonical JSON hashing; that does not establish zero instrumentation overhead for every provider. All 168 searches returned HTTP 200, with two downstream TMDB 404s. Repeated runs and larger category samples would strengthen conclusions.

What was the total request budget?

1,295 observed outbound HTTP attempts: 809 main-search requests, 252 pilot/setup requests, 36 validation requests, and 198 startup/background requests. These include enrichment and dataset checks, not just billable search calls. There were 204 isolated catalog attempts, including pilot correction and validation. Trakt was excluded. Temporary test containers and private configuration copies were removed afterward.
