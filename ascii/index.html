What this measures

168 original searches across six providers, plus 28 searches using Lumiere sha-0702a05. Each run has the same 14 movie and 14 show queries. The normal AIOMetadata Stremio catalog route includes metadata enrichment; Odin rendering, image downloads and Jellyfin lightweight search are not measured.

Quality and relevance

Title discovery scores 11 expected-title queries per media type. The cutoff changes where a target must appear, not how many results the provider returned. “All returned” means the saved first response; provider limits differ. TVDB contains unresolved native IDs, so its confirmed score may undercount matches.

Aliases, franchise queries and invented titles have separate reviews visible in the explorer. Franchise reviews check a defined reference set, not every related production. No-match controls pass only when the complete response is empty. Two year formats were tested for Blade Runner 2049, but no paired Goosebumps remake test was run.

Timing and cache conditions

Search lookups were computed or refreshed. Each provider had an isolated cache, equal initial seeds and a four-query pilot; enrichment caches evolved during the run. This is not a fully cold test. The last three original queries followed a test-app restart. Each query was timed once, so the charts are descriptive, not confidence estimates.

“Matched by every selected run” uses only scored queries where every selected provider found the target at your cutoff. Changing the selected providers can change that shared sample. All responses, including empty ones, are used by default.

The Lumiere update

The original Lumiere build was not recorded. The later run used 0702a05027889395feee1905eae1a879a34acdf1. Both used AIOMetadata 3.3.2, but the later run had no mid-run restart and ran at a different time. It is not a controlled build-only latency comparison.

Requests, fields and stages

HTTP attempts include search, enrichment and failures—not just billable provider calls. Stage durations can overlap; do not add or subtract them to estimate a feature-off response time. Artwork and trailer fields indicate presence only.

About this view

An independent, lightweight presentation inspired by Linecast’s terminal graphics. It uses native text, character bars and ordinary browser controls. No chart library, external fonts or provider API calls. The original dashboard is unchanged.
